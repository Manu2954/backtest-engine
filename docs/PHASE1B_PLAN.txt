PHASE 1A vs PHASE 1B COMPARISON
================================================================================

PHASE 1A (CURRENT - Simple Confluence):
Signal Strength = conditions_met / total_conditions

Example:
  Strategy: "RSI < 30 AND price > SMA_50"
  Entry 1: RSI=29, price > SMA → 2/2 conditions → strength = 1.0
  Entry 2: RSI=20, price > SMA → 2/2 conditions → strength = 1.0

  Problem: Both get same strength, but RSI=20 is MORE oversold (stronger signal)

PHASE 1B (PLANNED - Indicator-Aware):
Signal Strength = weighted average of per-condition strengths

Example (same strategy):
  Entry 1: RSI=29 → 0.52 strength, SMA cross → 0.50 strength → avg = 0.51
  Entry 2: RSI=20 → 0.83 strength, SMA cross → 0.50 strength → avg = 0.67

  Insight: Entry 2 is genuinely stronger (more extreme RSI)

EXPECTED IMPACT:
- Signal strength bins will be more meaningful
- "Strong" trades will have better win rates than "weak" trades
- Attribution reports will reveal which indicator extremes matter most

================================================================================
CALCULATOR 1: BOUNDED OSCILLATOR STRENGTH
================================================================================

PURPOSE:
Calculate signal strength for oscillators that have known bounds (0-100).
Strength increases as values approach extremes.

INDICATORS SUPPORTED:
- RSI (0-100, oversold <30, overbought >70)
- Stochastic (0-100, oversold <20, overbought >80)
- Williams %R (0-100, oversold <20, overbought >80)
- CCI (typically -200 to +200, extreme <-100, >+100)

ALGORITHM:

For RSI (0-100 scale):
  Oversold zone (<30):
    strength = 1.0 - (value / 30)
    Examples:
      RSI=30 → strength = 0.0 (just touching oversold)
      RSI=20 → strength = 0.33 (moderate oversold)
      RSI=10 → strength = 0.67 (deep oversold)
      RSI=0  → strength = 1.0 (extreme oversold)

  Neutral zone (30-70):
    strength = 0.0
    No extreme, no strength

  Overbought zone (>70):
    strength = (value - 70) / 30
    Examples:
      RSI=70 → strength = 0.0 (just touching overbought)
      RSI=80 → strength = 0.33 (moderate overbought)
      RSI=90 → strength = 0.67 (deep overbought)
      RSI=100 → strength = 1.0 (extreme overbought)

For conditions like "RSI > 70" (bullish overbought):
  - If RSI in overbought zone: Use overbought strength
  - If RSI in neutral/oversold: strength = 0.0 (condition not really met)

For conditions like "RSI < 30" (bullish oversold):
  - If RSI in oversold zone: Use oversold strength
  - If RSI in neutral/overbought: strength = 0.0

PARAMETERS (configurable):
- oversold_threshold: default 30 for RSI
- overbought_threshold: default 70 for RSI
- neutral_strength: default 0.0

PSEUDOCODE:
```python
class BoundedOscillatorStrengthCalculator(SignalStrengthCalculator):
    def __init__(self, oversold=30, overbought=70):
        self.oversold = oversold
        self.overbought = overbought

    def calculate_condition_strength(
        self,
        condition: Condition,
        indicator_value: float
    ) -> float:
        """
        Calculate strength for a single condition involving a bounded oscillator.

        Returns:
            float: 0.0-1.0 strength score
        """
        # Determine if condition expects oversold or overbought
        is_oversold_condition = self._is_oversold_condition(condition)
        is_overbought_condition = self._is_overbought_condition(condition)

        # Calculate zone-based strength
        if indicator_value < self.oversold:
            # In oversold zone
            if is_oversold_condition:
                return 1.0 - (indicator_value / self.oversold)
            else:
                return 0.0  # Wrong zone for this condition

        elif indicator_value > self.overbought:
            # In overbought zone
            if is_overbought_condition:
                return (indicator_value - self.overbought) / (100 - self.overbought)
            else:
                return 0.0  # Wrong zone for this condition

        else:
            # Neutral zone - no strength
            return 0.0

    def _is_oversold_condition(self, condition: Condition) -> bool:
        """Check if condition expects oversold (e.g., RSI < 30)"""
        return condition.operator in ['LT', 'LTE'] and \
               condition.right_operand_type == 'SCALAR' and \
               float(condition.right_operand_value) <= self.oversold

    def _is_overbought_condition(self, condition: Condition) -> bool:
        """Check if condition expects overbought (e.g., RSI > 70)"""
        return condition.operator in ['GT', 'GTE'] and \
               condition.right_operand_type == 'SCALAR' and \
               float(condition.right_operand_value) >= self.overbought
```

EDGE CASES:
1. Condition "RSI > 50" (neither extreme)
   → Neutral condition, return 0.5 (satisfied but not strong)

2. Condition "RSI == 30" (exact equality)
   → Return 0.0 (just touching threshold, not extreme)

3. Multiple oscillators in same condition group
   → Calculate strength per oscillator, return average

TEST SCENARIOS:
- RSI < 30 with RSI=29 → strength ~0.03
- RSI < 30 with RSI=20 → strength ~0.33
- RSI < 30 with RSI=10 → strength ~0.67
- RSI > 70 with RSI=71 → strength ~0.03
- RSI > 70 with RSI=90 → strength ~0.67
- RSI > 50 with RSI=60 → strength ~0.5 (neutral)
- RSI < 30 with RSI=80 → strength = 0.0 (wrong zone)

================================================================================
CALCULATOR 2: CROSSOVER STRENGTH
================================================================================

PURPOSE:
Calculate signal strength for crossover conditions based on:
1. How recent the crossover is (decay over time)
2. How strong the crossover was (magnitude)

INDICATORS SUPPORTED:
- MACD (macd crosses signal line)
- SMA/EMA crossovers (fast crosses slow)
- Price crosses MA
- Stochastic K crosses D

ALGORITHM:

Crossover Strength = recency_factor × magnitude_factor

RECENCY FACTOR (decay function):
  bars_since_cross = current_bar - crossover_bar
  recency = exp(-decay_rate × bars_since_cross)

  Examples (decay_rate=0.15):
    0 bars ago (just crossed) → recency = 1.0
    1 bar ago → recency = 0.86
    3 bars ago → recency = 0.64
    5 bars ago → recency = 0.47
    10 bars ago → recency = 0.22
    20 bars ago → recency = 0.05

MAGNITUDE FACTOR (how strong was the cross):
  For MACD crossing signal:
    magnitude = abs(macd - signal) / typical_separation
    strength = min(1.0, magnitude)  # Cap at 1.0

  For price crossing MA:
    magnitude = abs(price - ma) / (atr * 0.5)  # Normalize by volatility
    strength = min(1.0, magnitude)

DETECTING CROSSOVERS:
  CROSSES_ABOVE: value[t-1] <= reference[t-1] AND value[t] > reference[t]
  CROSSES_BELOW: value[t-1] >= reference[t-1] AND value[t] < reference[t]

  Lookback window: Check last 5 bars for most recent crossover

PSEUDOCODE:
```python
class CrossoverStrengthCalculator(SignalStrengthCalculator):
    def __init__(self, decay_rate=0.15, lookback_window=5):
        self.decay_rate = decay_rate
        self.lookback_window = lookback_window

    def calculate_condition_strength(
        self,
        condition: Condition,
        df: pd.DataFrame,
        current_bar: int
    ) -> float:
        """
        Calculate strength for crossover condition.

        Returns:
            float: 0.0-1.0 strength (decays with time since cross)
        """
        if condition.operator not in ['CROSSES_ABOVE', 'CROSSES_BELOW']:
            return 0.5  # Not a crossover, neutral strength

        # Find most recent crossover in lookback window
        crossover_bar = self._find_crossover(
            df, condition, current_bar, self.lookback_window
        )

        if crossover_bar is None:
            return 0.0  # No recent crossover found

        # Calculate recency factor
        bars_since_cross = current_bar - crossover_bar
        recency = np.exp(-self.decay_rate * bars_since_cross)

        # Calculate magnitude factor
        magnitude = self._calculate_magnitude(
            df, condition, crossover_bar
        )

        # Combined strength
        strength = recency * magnitude
        return min(1.0, strength)

    def _find_crossover(
        self,
        df: pd.DataFrame,
        condition: Condition,
        current_bar: int,
        lookback: int
    ) -> Optional[int]:
        """
        Find most recent bar where crossover occurred.

        Returns:
            int: Bar index of crossover, or None if not found
        """
        left_col = condition.left_operand_value
        right_col = condition.right_operand_value

        for i in range(current_bar, max(0, current_bar - lookback), -1):
            if i == 0:
                continue  # Can't check i-1

            if condition.operator == 'CROSSES_ABOVE':
                if df[left_col].iloc[i-1] <= df[right_col].iloc[i-1] and \
                   df[left_col].iloc[i] > df[right_col].iloc[i]:
                    return i

            elif condition.operator == 'CROSSES_BELOW':
                if df[left_col].iloc[i-1] >= df[right_col].iloc[i-1] and \
                   df[left_col].iloc[i] < df[right_col].iloc[i]:
                    return i

        return None

    def _calculate_magnitude(
        self,
        df: pd.DataFrame,
        condition: Condition,
        crossover_bar: int
    ) -> float:
        """
        Calculate how strong the crossover was.

        Returns:
            float: 0.0-1.0+ magnitude (can exceed 1.0 for very strong crosses)
        """
        left_col = condition.left_operand_value
        right_col = condition.right_operand_value

        # Get separation at crossover bar
        separation = abs(df[left_col].iloc[crossover_bar] -
                        df[right_col].iloc[crossover_bar])

        # Normalize by typical separation (using std dev as proxy)
        typical_sep = df[left_col].rolling(20).std().iloc[crossover_bar]

        if typical_sep > 0:
            magnitude = separation / typical_sep
        else:
            magnitude = 0.5  # Unknown, use neutral

        return magnitude
```

EDGE CASES:
1. Crossover happened >20 bars ago
   → strength ≈ 0.0 (too old, not relevant)

2. Multiple crossovers in lookback window
   → Use most recent (closest to current_bar)

3. Crossover on current bar (bars_since_cross=0)
   → strength = 1.0 × magnitude (maximum recency)

4. Very weak crossover (tiny separation)
   → Low magnitude factor reduces strength

TEST SCENARIOS:
- MACD crosses above signal 1 bar ago, strong separation → strength ~0.85
- MACD crosses above signal 5 bars ago, weak separation → strength ~0.20
- MACD crosses above signal 15 bars ago → strength ~0.05
- Price crosses above SMA on current bar, strong → strength ~1.0
- No crossover found in last 5 bars → strength = 0.0

================================================================================
CALCULATOR 3: MOMENTUM STRENGTH
================================================================================

PURPOSE:
Calculate strength for momentum indicators (ADX, ROC) based on
how strong the directional movement is.

INDICATORS SUPPORTED:
- ADX (measures trend strength, 0-100+)
- ROC (Rate of Change, percentage)
- Momentum (price difference)

ALGORITHM:

For ADX:
  ADX measures trend strength (not direction)
  - ADX < 20: Weak/no trend → strength = 0.0
  - ADX 20-25: Emerging trend → strength = 0.0-0.25
  - ADX 25-50: Strong trend → strength = 0.25-1.0
  - ADX > 50: Very strong trend → strength = 1.0

  Formula: strength = min(1.0, (adx - 20) / 30)

  Examples:
    ADX=15 → strength = 0.0 (no trend)
    ADX=20 → strength = 0.0 (threshold)
    ADX=30 → strength = 0.33 (moderate trend)
    ADX=40 → strength = 0.67 (strong trend)
    ADX=50+ → strength = 1.0 (very strong trend)

For ROC (Rate of Change):
  ROC measures momentum as percentage change
  - Normalize by typical ROC range (std dev)
  - Strength increases with extreme ROC values

  Formula: strength = min(1.0, abs(roc) / typical_roc)

  Examples (typical_roc = 5%):
    ROC=±2% → strength = 0.4 (weak momentum)
    ROC=±5% → strength = 1.0 (strong momentum)
    ROC=±10% → strength = 1.0 (capped, very strong)

PSEUDOCODE:
```python
class MomentumStrengthCalculator(SignalStrengthCalculator):
    def __init__(self, adx_threshold=20, adx_max=50):
        self.adx_threshold = adx_threshold
        self.adx_max = adx_max

    def calculate_condition_strength(
        self,
        condition: Condition,
        indicator_value: float,
        indicator_type: str
    ) -> float:
        """
        Calculate strength for momentum indicator.

        Returns:
            float: 0.0-1.0 strength
        """
        if indicator_type == 'ADX':
            return self._adx_strength(indicator_value)

        elif indicator_type == 'ROC':
            return self._roc_strength(indicator_value)

        else:
            return 0.5  # Unknown momentum indicator, neutral

    def _adx_strength(self, adx: float) -> float:
        """Calculate ADX-based strength (trend strength)"""
        if adx < self.adx_threshold:
            return 0.0  # No trend

        strength = (adx - self.adx_threshold) / (self.adx_max - self.adx_threshold)
        return min(1.0, strength)

    def _roc_strength(self, roc: float, typical_roc: float = 5.0) -> float:
        """Calculate ROC-based strength (momentum)"""
        strength = abs(roc) / typical_roc
        return min(1.0, strength)
```

TEST SCENARIOS:
- ADX > 25 with ADX=30 → strength ~0.33
- ADX > 25 with ADX=50 → strength = 1.0
- ADX > 25 with ADX=15 → strength = 0.0 (condition not really met)
- ROC > 5 with ROC=10 → strength = 1.0 (strong momentum)
- ROC > 5 with ROC=6 → strength ~0.2 (weak momentum)

================================================================================
CALCULATOR 4: VOLATILITY ADJUSTED
================================================================================

PURPOSE:
Adjust signal strength based on current volatility regime.
High volatility → reduce strength (more false signals)
Low volatility → normal strength (cleaner signals)

VOLATILITY METRIC: ATR (Average True Range)

ALGORITHM:

Volatility Adjustment Factor:
  current_atr = ATR at current bar
  typical_atr = 20-period SMA of ATR
  volatility_ratio = current_atr / typical_atr

  adjustment = 1.0 / (1.0 + max(0, volatility_ratio - 1.0))

  Examples:
    volatility_ratio = 1.0 (normal) → adjustment = 1.0 (no change)
    volatility_ratio = 1.5 (50% higher) → adjustment = 0.67 (reduce strength)
    volatility_ratio = 2.0 (double) → adjustment = 0.50 (halve strength)
    volatility_ratio = 0.5 (half) → adjustment = 1.0 (no boost, cap at 1.0)

Applied Strength:
  base_strength = strength from other calculator (e.g., BoundedOscillator)
  adjusted_strength = base_strength × volatility_adjustment

PSEUDOCODE:
```python
class VolatilityAdjustedCalculator(SignalStrengthCalculator):
    def __init__(self, base_calculator: SignalStrengthCalculator):
        self.base_calculator = base_calculator

    def calculate_strength(
        self,
        conditions: List[Condition],
        df: pd.DataFrame,
        current_bar: int
    ) -> float:
        """
        Calculate strength with volatility adjustment.

        Returns:
            float: 0.0-1.0 adjusted strength
        """
        # Get base strength from wrapped calculator
        base_strength = self.base_calculator.calculate_strength(
            conditions, df, current_bar
        )

        # Calculate volatility adjustment
        adjustment = self._volatility_adjustment(df, current_bar)

        # Apply adjustment
        adjusted_strength = base_strength * adjustment
        return adjusted_strength

    def _volatility_adjustment(
        self,
        df: pd.DataFrame,
        current_bar: int
    ) -> float:
        """
        Calculate volatility-based adjustment factor.

        Returns:
            float: 0.0-1.0 adjustment (1.0 = no adjustment)
        """
        if 'atr' not in df.columns:
            return 1.0  # No ATR data, no adjustment

        current_atr = df['atr'].iloc[current_bar]
        typical_atr = df['atr'].rolling(20).mean().iloc[current_bar]

        if typical_atr == 0:
            return 1.0

        volatility_ratio = current_atr / typical_atr

        # Penalize high volatility, no bonus for low volatility
        adjustment = 1.0 / (1.0 + max(0, volatility_ratio - 1.0))

        return adjustment
```

TEST SCENARIOS:
- Base strength=0.8, normal volatility (ratio=1.0) → adjusted=0.8
- Base strength=0.8, high volatility (ratio=2.0) → adjusted=0.4
- Base strength=0.8, very high volatility (ratio=3.0) → adjusted=0.27
- Base strength=0.8, low volatility (ratio=0.5) → adjusted=0.8 (no boost)

================================================================================
CALCULATOR 5: HYBRID CALCULATOR (MASTER)
================================================================================

PURPOSE:
Intelligently combine all above calculators based on auto-detected indicator types.
This becomes the new default calculator, replacing simple confluence.

LOGIC:
For each condition in a condition group:
  1. Detect indicator type (RSI, MACD, ADX, etc.)
  2. Route to appropriate calculator:
     - RSI/Stochastic → BoundedOscillatorStrength
     - MACD/MA crossovers → CrossoverStrength
     - ADX/ROC → MomentumStrength
     - Unknown → Confluence (fallback)
  3. Calculate per-condition strength
  4. Average all condition strengths → group strength

INDICATOR TYPE DETECTION:
```python
def detect_indicator_type(indicator_alias: str) -> str:
    """
    Detect indicator type from alias.

    Returns:
        str: 'RSI', 'MACD', 'SMA', 'ADX', 'ROC', 'STOCH', 'UNKNOWN'
    """
    alias_lower = indicator_alias.lower()

    if 'rsi' in alias_lower:
        return 'RSI'
    elif 'macd' in alias_lower:
        return 'MACD'
    elif 'sma' in alias_lower or 'ema' in alias_lower:
        return 'MA'
    elif 'adx' in alias_lower:
        return 'ADX'
    elif 'roc' in alias_lower:
        return 'ROC'
    elif 'stoch' in alias_lower:
        return 'STOCH'
    elif 'bb' in alias_lower:
        return 'BB'
    else:
        return 'UNKNOWN'
```

PSEUDOCODE:
```python
class HybridStrengthCalculator(SignalStrengthCalculator):
    def __init__(self):
        self.oscillator_calc = BoundedOscillatorStrengthCalculator()
        self.crossover_calc = CrossoverStrengthCalculator()
        self.momentum_calc = MomentumStrengthCalculator()
        self.volatility_calc = VolatilityAdjustedCalculator(self)

    def calculate_strength(
        self,
        conditions: List[Condition],
        df: pd.DataFrame,
        current_bar: int,
        indicators_used: List[str]
    ) -> float:
        """
        Calculate hybrid strength by routing to appropriate calculators.

        Returns:
            float: 0.0-1.0 average strength across all conditions
        """
        condition_strengths = []

        for condition in conditions:
            # Get indicator involved in condition
            indicator = self._get_condition_indicator(condition, indicators_used)
            indicator_type = detect_indicator_type(indicator)

            # Route to appropriate calculator
            if indicator_type in ['RSI', 'STOCH']:
                strength = self.oscillator_calc.calculate_condition_strength(
                    condition, df[indicator].iloc[current_bar]
                )

            elif condition.operator in ['CROSSES_ABOVE', 'CROSSES_BELOW']:
                strength = self.crossover_calc.calculate_condition_strength(
                    condition, df, current_bar
                )

            elif indicator_type in ['ADX', 'ROC']:
                strength = self.momentum_calc.calculate_condition_strength(
                    condition, df[indicator].iloc[current_bar], indicator_type
                )

            else:
                # Fallback: Simple condition met = 1.0, not met = 0.0
                strength = 1.0 if self._is_condition_met(condition, df, current_bar) else 0.0

            condition_strengths.append(strength)

        # Average across all conditions
        avg_strength = sum(condition_strengths) / len(condition_strengths)

        # Apply volatility adjustment (optional)
        if self._should_apply_volatility_adjustment(df):
            avg_strength = self.volatility_calc._volatility_adjustment(df, current_bar) * avg_strength

        return avg_strength
```

TEST SCENARIOS:
- "RSI < 30 AND MACD crosses above signal"
  - RSI=20 → oscillator strength = 0.67
  - MACD crossed 2 bars ago → crossover strength = 0.74
  - Hybrid strength = (0.67 + 0.74) / 2 = 0.705

- "ADX > 25 AND price > SMA"
  - ADX=40 → momentum strength = 0.67
  - price > SMA (no crossover) → fallback strength = 1.0
  - Hybrid strength = (0.67 + 1.0) / 2 = 0.835

- High volatility scenario (ATR 2x normal)
  - Base hybrid strength = 0.70
  - Volatility adjustment = 0.50
  - Final strength = 0.70 × 0.50 = 0.35
