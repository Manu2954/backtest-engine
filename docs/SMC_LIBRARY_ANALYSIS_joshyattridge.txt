================================================================================
                    ALGORITHMIC APPROACHES (REVERSE-ENGINEERED)
================================================================================

Based on API and documentation, here's how each concept is likely detected:

1. FAIR VALUE GAP (FVG)
------------------------
Algorithm:
  - Compare bar[i].high with bar[i+2].low (bullish gap)
  - Compare bar[i].low with bar[i+2].high (bearish gap)
  - Check if middle bar (i+1) doesn't fill the gap
  - Optional: Join consecutive FVGs into single zone

Parameters:
  - join_consecutive: bool (merge adjacent FVGs)

Output Columns:
  - FVG_bullish: Price level of bullish FVG
  - FVG_bearish: Price level of bearish FVG


2. SWING HIGHS / LOWS
----------------------
Algorithm:
  - Lookback and lookahead comparison
  - High is swing high if higher than N bars before and N bars after
  - Low is swing low if lower than N bars before and N bars after

Parameters:
  - swing_length: int (default 50) - lookback/lookahead period

Output Columns:
  - swing_high: Price level if swing high, else NaN
  - swing_low: Price level if swing low, else NaN


3. BREAK OF STRUCTURE (BOS) / CHANGE OF CHARACTER (CHoCH)
----------------------------------------------------------
Algorithm:
  - Uses swing_highs_lows() as prerequisite
  - BOS: Price breaks above previous swing high (uptrend)
  - BOS: Price breaks below previous swing low (downtrend)
  - CHoCH: Break reverses previous trend direction

Parameters:
  - swing_length: int
  - close_break: bool (require close above/below, not just wick)

Output Columns:
  - BOS_bullish: True if bullish BOS
  - BOS_bearish: True if bearish BOS
  - CHoCH: True if change of character


4. ORDER BLOCKS (OB)
---------------------
Algorithm (inferred):
  - Volume accumulation analysis
  - Find high-volume zones near swing reversals
  - "Strength of order block" = volume ratio calculation
  - Likely: Last opposite candle before swing + volume filter

Parameters:
  - swing_length: int

Output Columns:
  - OB_bullish_high: Top of bullish OB
  - OB_bullish_low: Bottom of bullish OB
  - OB_bearish_high: Top of bearish OB
  - OB_bearish_low: Bottom of bearish OB
  - OB_strength: Numerical strength score


5. LIQUIDITY DETECTION
-----------------------
Algorithm:
  - Range-percent proximity clustering
  - Find areas where multiple swing highs/lows cluster
  - Threshold: X% range tolerance for "equal" levels

Parameters:
  - range_percent: float (tolerance for clustering)

Output Columns:
  - Liquidity_high: Price level of buy-side liquidity
  - Liquidity_low: Price level of sell-side liquidity


6. PREVIOUS HIGH/LOW
---------------------
Algorithm:
  - Track highest high and lowest low over lookback period
  - Per-timeframe tracking (if multiple TFs provided)

Parameters:
  - None (uses full history)

Output Columns:
  - prev_high: Highest price in period
  - prev_low: Lowest price in period


7. SESSIONS
------------
Algorithm:
  - Time-based detection using datetime index
  - London: 03:00-12:00 UTC
  - New York: 13:00-22:00 UTC
  - Asia: 00:00-09:00 UTC (approximate)

Parameters:
  - None (hardcoded session times)

Output Columns:
  - session: String ("London", "New York", "Asia", "None")


8. RETRACEMENTS
----------------
Algorithm:
  - Calculate pullback percentage from swing high to swing low
  - Fibonacci-style levels (0.382, 0.5, 0.618, etc.)

Parameters:
  - levels: list of float (Fibonacci ratios)

Output Columns:
  - retracement_0.382: Price level
  - retracement_0.5: Price level
  - retracement_0.618: Price level

Pseudocode:
```python
# backend/app/engine/smc_layer.py
from smartmoneyconcepts import smc

def apply_smc_concepts(df: pd.DataFrame, config: dict) -> pd.DataFrame:
    """Apply SMC concepts to OHLCV DataFrame."""

    # Convert to lowercase columns (required by library)
    df_lower = df.copy()
    df_lower.columns = df_lower.columns.str.lower()

    # Apply SMC detections
    if config.get('detect_fvg', True):
        df_lower = smc.fvg(df_lower, join_consecutive=False)

    if config.get('detect_swings', True):
        swing_length = config.get('swing_length', 50)
        df_lower = smc.swing_highs_lows(df_lower, swing_length=swing_length)

    if config.get('detect_ob', True):
        df_lower = smc.ob(df_lower, swing_length=20)

    if config.get('detect_bos', True):
        df_lower = smc.bos(df_lower, swing_length=50, close_break=True)

    if config.get('detect_liquidity', True):
        df_lower = smc.liquidity(df_lower, range_percent=0.01)

    # Convert back to your format (if needed)
    # Merge SMC columns into original DataFrame

    return df
```
