REFERENCES
================================================================================

L1 Trend Filtering:
- Paper: "l1 Trend Filtering" (Kim et al., 2009)
- Implementation: CVXPY with CLARABEL solver
- Formula: minimize ||y - x||² + λ * ||D²x||₁
- Parameter: λ = k * n, where k ∈ [0.01, 0.02]

PELT (Pruned Exact Linear Time):
- Library: ruptures (Python)
- Model: RBF kernel for non-linear changepoints
- Signals tested: rolling_mean, [returns, vol]
- Penalty: log(n) * multiplier

Production Labeling:
- OLS regression for slope and R²
- R² threshold: 75th percentile (adaptive)
- Slope direction: BULL (>0) vs BEAR (<0)
- Volatility split: CHOPPY (high std) vs RANGING (low std)
