API INTEGRATION FLOW
================================================================================

**End-to-End Attribution Flow:**

1. **User creates backtest (POST /api/backtests)**
   ```json
   {
       "strategy_id": "abc-123",
       "ticker": "AAPL",
       "start_date": "2023-01-01",
       "end_date": "2023-12-31",
       "initial_capital": 10000,
       "enable_attribution": true  ← NEW
   }
   ```

2. **API creates BacktestRun with enable_attribution=true**
   - Stored in database
   - Celery task started

3. **Celery task reads enable_attribution flag**
   - Passes to run_backtest() (Step 4 integration)
   - Attribution captured during backtest
   - generate_attribution_report() called (Step 5 integration)

4. **BacktestRun.report contains attribution**
   ```json
   {
       "total_return_pct": 12.5,
       "sharpe_ratio": 1.2,
       "attribution": {  ← NEW
           "total_alpha": 5.23,
           "alpha_percentage": 52.3,
           "signal_strength": {
               "strong": {"count": 8, "win_rate": 75.0, "avg_alpha": 0.85},
               "medium": {...},
               "weak": {...}
           },
           "condition_frequency": {...}
       }
   }
   ```

5. **User fetches results (GET /api/backtests/{id})**
   - Response includes report["attribution"]

6. **User fetches trades (GET /api/backtests/{id}/trades)**
   ```json
   [
       {
           "entry_date": "2023-02-15",
           "entry_price": 150.0,
           "exit_date": "2023-02-20",
           "exit_price": 155.0,
           "pnl": 500.0,
           "pnl_pct": 3.33,
           "entry_conditions_met": ["abc-123", "def-456"],  ← NEW
           "entry_signal_strength": 0.85,  ← NEW
           "market_return_during_trade": 1.5,  ← NEW
           "alpha": 1.83,  ← NEW
           "indicator_snapshot_entry": {"rsi_14": 35.2, "sma_50": 148.5}  ← NEW
       }
   ]
   ```

API ENDPOINT SUMMARY
================================================================================

**POST /api/backtests**
- Request: BacktestCreate (includes enable_attribution)
- Response: BacktestOut (includes enable_attribution)
- Creates backtest run with attribution flag

**GET /api/backtests**
- Request: Query params (user_id, strategy_id, limit, offset)
- Response: List[BacktestOut] (each includes enable_attribution)
- Lists all backtests with attribution flag visible

**GET /api/backtests/{run_id}**
- Request: run_id path parameter
- Response: BacktestOut (includes enable_attribution, report["attribution"])
- Returns single backtest with full report including attribution

**GET /api/backtests/{run_id}/trades**
- Request: run_id path parameter, limit/offset query params
- Response: List[TradeLogOut] (each includes 7 attribution fields)
- Returns trades with full attribution data per trade
