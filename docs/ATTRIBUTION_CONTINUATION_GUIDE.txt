KEY DESIGN DECISIONS FOR STATE MACHINE
================================================================================

1. **Backward Compatibility:** enable_attribution defaults to True but is optional
2. **Performance:** Attribution code only runs when enable_attribution=True
3. **Condition Groups:** Must be passed explicitly (not inferred from signals)
4. **Direction Tracking:** Need to add direction="LONG"|"SHORT" (currently assumes LONG)
5. **Error Handling:** Attribution failures shouldn't break backtest (fallback to None values)
