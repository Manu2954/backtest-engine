================================================================================
KEY IMPLEMENTATION FIXES
================================================================================

**1. DataFrame Access Pattern:**
- Original: `df.loc[index, column]` (assumes index is datetime)
- Fixed: `df.iloc[position][column]` (uses integer position)
- Reason: State machine passes integer bar_idx, not datetime

**2. Condition Field Names:**
- Original: `condition['left_operand']`
- Fixed: `condition['left_operand_value']`
- Reason: Actual condition format uses '_value' suffix

**3. Market Return Format:**
- Original: Returns decimal (0.05 for 5%)
- Fixed: Returns percentage (5.0 for 5%)
- Reason: Matches pnl_pct format in trade records

**4. Error Handling:**
- Original: Raises ValueError for invalid direction
- Fixed: Defaults to LONG behavior
- Reason: Prevents backtest breakage from attribution failures

**5. Bounds Checking:**
- Original: No bounds checking
- Fixed: Checks `bar_idx < 0 or >= len(df)`, returns safe defaults
- Reason: Prevents KeyError/IndexError crashes
