**Signal Strength Analysis:**

- Provides actionable insights: "Your strong signals have 75% win rate"
- Helps users tune strategy conditions

**Condition Frequency:**
- Identifies which conditions trigger most often
- Helps spot overused or underused conditions
- Stored as dict: {condition_id_str: count}

**Alpha Calculation:**
- Total alpha: Sum of skill across all trades
- Alpha percentage: What % of return is skill vs market
- Example: 10% return, 3% market, 7% alpha → 70% alpha percentage

**NaN/Inf Sanitization:**
- All float values checked for NaN/Inf
- Replaced with 0.0 or ±999999.0 (PostgreSQL JSONB compatible)

================================================================================
EXAMPLE ATTRIBUTION REPORT
================================================================================

```json
{
    "total_alpha": 5.23,
    "alpha_percentage": 52.3,
    "signal_strength": {
        "strong": {
            "count": 8,
            "win_rate": 75.0,
            "avg_alpha": 0.85
        },
        "medium": {
            "count": 12,
            "win_rate": 58.3,
            "avg_alpha": 0.42
        },
        "weak": {
            "count": 5,
            "win_rate": 40.0,
            "avg_alpha": -0.15
        }
    },
    "condition_frequency": {
        "abc-123-def-456": 15,
        "xyz-789-uvw-012": 10,
        "foo-345-bar-678": 8
    }
}
```

**Interpretation:**
- Total skill (alpha): +5.23% across all trades
- 52.3% of returns due to skill (rest is market)
- Strong signals (>0.7): 75% win rate, avg +0.85% alpha per trade
- Weak signals (<0.3): 40% win rate, avg -0.15% alpha per trade
- Condition abc-123 triggered most often (15 trades)
