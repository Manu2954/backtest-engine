DECISION 1: PRODUCT POSITIONING SHIFT
================================================================================

FROM: "Backtest Engine" (commodity tool)
TO:   "Truth Engine" (strategy validation platform)

REASONING:
- General-purpose backtest engines are commoditized (TradingView, Backtrader,
  QuantConnect all free or cheap)
- Cannot compete on features alone - established players have years of dev
- Real pain point: Traders get deceived by backtests (overfitting, regime bias,
  execution assumptions)
- Gap in market: Tools that tell you IF your strategy will work, not just HOW
  it performed historically

IMPACT:
- Changes entire value proposition from "run backtests" to "validate truth"
- Shifts target market from retail traders to serious/semi-pro traders
- Justifies premium pricing ($100-$500/month vs $20-$50/month)
- Creates defensible moat (hard to build well, requires domain expertise)

KEY QUOTE:
"We need to upgrade from 'Engine that runs strategies' to 'Engine that
evaluates truth of strategies'"

VALIDATION:
- Aligns with customer pain: "Why did backtest show 40% but live got 8%?"
- Differentiates from all competitors (nobody positions as "truth validator")
- Addresses root cause: Confidence in strategy before risking capital

DECISION 2: REJECT SMC-FOCUSED NICHE
================================================================================

DECISION: Do NOT build "SMC/ICT-specific backtesting platform"

REASONING:
- SMC market is retail-heavy (low capital, low willingness to pay)
- Hype-driven demand (ICT popular now, might fade in 12-18 months)
- High churn (blown accounts, short attention spans)
- Won't pay for software ($20-$50/month max, prefer free TradingView scripts)
- Market expects courses/signals, not infrastructure tools

ALTERNATIVE CONSIDERED:
"SMC-native backtest engine with pre-built FVG/OB indicators"

WHY REJECTED:
- Niche too small with low monetization potential
- Hype cycle risk (what if ICT trend ends?)
- Retail traders prefer manual analysis over automation
- Can't build sustainable business on retail SMC traders

STRATEGIC PIVOT:
- Build paradigm-agnostic truth engine
- SMC becomes one "strategy pack" option, not the core product
- Target serious traders (prop, semi-pro, small funds) not retail

IMPACT:
- Avoids low-value market trap
- Opens door to institutional/semi-institutional customers
- Sustainable business model (not hype-dependent)

DECISION 3: TRUTH ENGINE FEATURE PRIORITIES
================================================================================

CORE TRUTH ENGINE COMPONENTS (What makes it a "truth engine"):

1. ROBUSTNESS LAYER
   - Parameter sensitivity analysis (±20% variations)
   - Monte Carlo simulation (1000+ runs with timing variations)
   - Walk-forward optimization (rolling windows, unseen data)
   - Output: Confidence score 0-100 ("Is this edge real or lucky?")

2. REGIME DETECTION LAYER
   - Market regime classification (trend/range, vol clusters, correlation)
   - Performance breakdown by regime
   - Regime transition analysis
   - Output: "Works in X regime, fails in Y regime"

3. EXECUTION REALITY LAYER
   - Slippage models (spread, market impact, partial fills)
   - Liquidity constraints (can you enter this size?)
   - Latency simulation (signal-to-execution delay)
   - Output: Reality-adjusted returns (backtest vs expected live)

4. FAILURE MODE DETECTION
   - Drawdown clustering (loses in streaks?)
   - Black swan sensitivity (what if Oct 2008 happens?)
   - Correlation breakdown (fails when everything correlates?)
   - Output: "Here's how this strategy dies"

REASONING:
These four components answer the core question: "Will this strategy work in
production, or am I fooling myself?"

COMPETITIVE ANALYSIS:
- Tier 1 (Commodity): Basic backtest - TradingView, Backtrader
- Tier 2 (Table stakes): Good execution modeling - QuantConnect, Alpaca
- Tier 3 (Differentiation): Truth validation - Almost nobody at retail price
  (institutional tools like Quantopian/Numerai cost $10k+/month)

MARKET POSITION:
Competing at Tier 3 with Tier 2 pricing ($100-$500/month)

DECISION 4: FEATURE RANKING - WHAT TO BUILD NEXT
================================================================================

TIER 1: CRITICAL FOR TRUTH ENGINE (Build First)

1. Trade Attribution / Explainability Layer - HIGHEST PRIORITY
   WHY: Core differentiator. Answers "Why did trades work?"
   - Per-trade breakdown (which condition triggered?)
   - Attribution analysis (% P&L from entries vs exits vs beta)
   - Counterfactual testing ("What if I removed RSI condition?")
   - Separates skill from luck
   IMPACT: This IS the truth engine. Without this, you're just another backtester.

2. Data Quality + Signal Integrity Layer - HIGH PRIORITY
   WHY: Can't evaluate truth with bad data. Trust builder.
   - Data validation (gaps, outliers, suspicious patterns)
   - Lookahead bias detection ("Your indicator uses future data")
   - Realism enforcement ("You're buying more than daily volume")
   IMPACT: Credibility foundation. Users trust the "truth" you're showing.

TIER 2: POWERFUL UPGRADES (Build After Core)

3. Portfolio-Level Backtesting - MEDIUM-HIGH PRIORITY
   WHY: Serious traders run multiple strategies. Portfolio view required.
   - Multi-strategy orchestration (shared capital, correlation)
   - Portfolio-level metrics (total drawdown, capital efficiency)
   - Risk allocation across strategies
   IMPACT: Moves from retail to semi-pro/institutional territory.

4. Event-Based Backtesting - MEDIUM PRIORITY
   WHY: Unique angle (most backtesters ignore events)
   - Event feed integration (on-chain, news, economic calendar)
   - Event-driven triggers ("Enter when funding rate > 0.1%")
   - Event attribution
   IMPACT: Niche differentiation, especially for crypto.

TIER 3: RISKY / DEPRIORITIZED

5. Strategy Discovery Engine - LOW PRIORITY / RISKY
   WHY RISKY: Conflicts with "truth" positioning
   - Auto-generated strategies are usually curve-fit garbage
   - If users lose money on discovered strategies, kills brand trust
   - Implies "easy alpha" which conflicts with "we tell hard truths"

   ALTERNATIVE: "Strategy Improvement" not "Discovery"
   - User brings strategy
   - Engine suggests: "Try adding ATR filter - 15% better Sharpe"
   - Lower risk, maintains truth-telling brand

REASONING FOR RANKING:
- Attribution = defines what "truth engine" means (without this, it's just backtest)
- Data Quality = enables trust in the truth being shown
- Portfolio = serious trader feature (high willingness to pay)
- Event-based = nice-to-have, niche use case
- Discovery = brand risk (only if done with heavy robustness filters)

2. NO BLOCKERS
   - Truth engine core works on ANY strategy (indicators, SMC, price action)
   - Can test with simpler strategies already supported (SMA, RSI, MACD)
   - SMC validation doesn't block any other features

3. STRATEGIC PRIORITY
   - Truth engine features are the differentiator (attribution, robustness)
   - SMC is one strategy type, not the product itself
   - Better to prove core engine value first

4. MODULAR APPROACH
   - Launch: "Truth engine for indicator-based strategies"
   - Add later: "SMC strategy pack" (after validation, if needed)
   - SMC becomes optional add-on, not foundation

WHEN TO RESUME:

- Have 2-3 weeks to dedicate to labeling + validation
- Need SMC as marketing differentiator
