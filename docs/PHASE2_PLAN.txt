WHAT IT DOES:
Tests strategy performance as you vary indicator parameters by ±10%, ±20%, ±30%

EXAMPLE:
Base strategy: RSI(period=14) < 30 → entry

Variants to test:
  - RSI(period=10) < 30
  - RSI(period=12) < 30
  - RSI(period=14) < 30  ← baseline
  - RSI(period=16) < 30
  - RSI(period=18) < 30
  - RSI(period=20) < 30

Run backtest for each variant, compare:
  - Total return
  - Sharpe ratio
  - Win rate
  - Max drawdown

INTERPRETATION:
  ROBUST: Metrics vary < 20% across variants
  MODERATE: Metrics vary 20-50%
  FRAGILE: Metrics vary > 50% (highly parameter-dependent = overfit)

def generate_parameter_variants(
    strategy: Strategy,
    variation_pct: float = 0.2  # ±20%
) -> list[Strategy]:
    """
    Generate strategy variants with parameter variations.

    For each indicator parameter (period, length, etc.):
    - Create variant with param * (1 - variation_pct)
    - Create variant with param * (1 + variation_pct)

    Returns list of Strategy objects with modified indicator params.
    """

def run_sensitivity_analysis(
    strategy_id: UUID,

def calculate_stability_score(
    baseline_metrics: dict,
    variant_metrics: list[dict]

    Calculate stability score (0.0-1.0).

    1.0 = perfectly stable (all variants have same metrics)

def assess_robustness_level(

    """

    MODERATE: 0.6 <= stability_score <= 0.8
    FRAGILE: stability_score < 0.6

================================================================================
COMPONENT 2: MONTE CARLO SIMULATION
================================================================================

WHAT IT DOES:
Runs 1000+ backtests with randomized entry/exit timing to measure luck vs skill

HOW IT WORKS:
1. Take original entry/exit signals
2. For each Monte Carlo run:
   - Randomly shift entry timing ±1-2 bars
   - Randomly shift exit timing ±1-2 bars
   - Re-run backtest
3. Collect distribution of returns
4. Calculate confidence intervals

EXAMPLE OUTPUT:
```
1000 Monte Carlo runs:
  Median return: 12.5%
  95% confidence interval: [8.2%, 18.3%]
  Best case: 25.1%
  Worst case: -3.2%

Assessment: Strategy shows positive returns in 92% of simulations.
Risk: MODERATE (wide confidence interval suggests timing luck)
```

    entry_signal: pd.Series,
    exit_signal: pd.Series,
    shift_bars: int = 2
) -> tuple[pd.Series, pd.Series]:
    """
    Randomly shift entry/exit signals by ±shift_bars.

    For each True in signal:
    - Randomly shift to ±shift_bars position
    - Ensure signals remain valid (entry before exit)
    """

def run_monte_carlo_simulation(
    strategy_id: UUID,
    backtest_params: BacktestCreate,
    num_simulations: int = 1000,
    shift_bars: int = 2
) -> MonteCarloReport:
    """
    Main entry point.

    1. Run baseline backtest
    2. Get entry/exit signals
    3. For each simulation:
       - Generate randomized signals
       - Run backtest
       - Record metrics
    4. Calculate distribution statistics
    5. Generate report
    """

def calculate_confidence_intervals(
    returns: list[float],
    confidence_level: float = 0.95
) -> dict:
    """
    Calculate percentile-based confidence intervals.

    Returns:
    {
        "median": 12.5,
        "mean": 12.8,
        "std_dev": 4.2,
        "ci_lower": 8.2,  # 2.5th percentile
        "ci_upper": 18.3, # 97.5th percentile

    MODERATE: positive_ratio > 0.80 OR ci_width < 30%

================================================================================
COMPONENT 3: WALK-FORWARD OPTIMIZATION
================================================================================

WHAT IT DOES:
Tests strategy on rolling windows to detect overfitting

HOW IT WORKS:
1. Divide data into windows: Train (70%) + Test (30%)
2. For each window:
   - Optimize parameters on train data (find best params)
   - Test on unseen test data
   - Record in-sample vs out-of-sample performance
3. Compare degradation

EXAMPLE:
```
Window 1: Train (2023-01 to 2023-08), Test (2023-09 to 2023-12)
  In-sample:  18% return, 2.1 Sharpe
  Out-sample: 12% return, 1.5 Sharpe
  Degradation: 33% return drop, 29% Sharpe drop

Window 2: Train (2023-04 to 2023-11), Test (2023-12 to 2024-03)
  ...

Assessment: OVERFIT (avg 40% degradation on out-of-sample data)
```

================================================================================
COMPONENT 5: REGIME DETECTION
================================================================================

WHAT IT DOES:
Classifies market periods (bull/bear/sideways) and shows when strategy works

HOW IT WORKS:
1. Detect regimes using:
   - SMA slopes (trending up/down/flat)
   - Volatility (ATR)
   - Momentum (ROC)
2. Label each bar with regime
3. Calculate strategy performance per regime
4. Identify regime dependency

EXAMPLE OUTPUT:
```
Regime Analysis:

Bull Market (45% of time):
  Strategy return: +22.5%
  Win rate: 75%
  Trades: 30
  Assessment: EXCELLENT

Bear Market (25% of time):
  Strategy return: -8.2%
  Win rate: 35%
  Trades: 15
  Assessment: POOR

Sideways (30% of time):
  Strategy return: +3.1%
  Win rate: 52%
  Trades: 20
  Assessment: BREAKEVEN

Overall Assessment:
  Strategy is REGIME-DEPENDENT (works in bull, fails in bear)

Recommendation:
  Add regime filter: Only trade when market is trending up
  Expected improvement: +15% return, -60% drawdown
```

- Parallel: ~15 minutes
